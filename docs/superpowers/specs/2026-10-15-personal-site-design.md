# 梁潇个人网站设计

用户确认个人品牌首页与精选项目方向，并指定蓝色点缀。米白背景、深蓝文字、明亮蓝色、编辑式排版；首页以 AI 产业、企业战略、国际合作为主线。

单页包含首页、个人介绍、七个项目、三段工作经历、教育与发表、联系入口。中文默认，可切换英文；项目按领域筛选并展开详情。依据 20261015 简历，不把规划或探索表述为已实现成果。WHO 文献仅列为简历所列出版条目，不宣称作者身份。邮箱沿用现有公开配置，不额外突出电话。

根目录 index.html、styles.css、script.js，直接兼容 GitHub Pages。删除旧 index.md 避免重复首页。保留既有 PDF 但不链接为最新版。手机适配，键盘可访问，减少动态偏好支持，无外部字体或脚本依赖。验证资源、链接、中英切换、筛选、展开、手机宽度与桌面布局。
