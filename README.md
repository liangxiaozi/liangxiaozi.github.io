# 梁潇 / Xiao Liang

A bilingual personal portfolio: AI industry, strategic research and international cooperation.

## Preview

Run `python3 -m http.server 8000`, then visit http://localhost:8000.
No installation or build is required. Chinese content remains accessible with JavaScript disabled.

## GitHub Pages

Push the website files to the `main` branch of `liangxiaozi/liangxiaozi.github.io`.
Under **Settings → Pages**, select **Deploy from a branch → main → / (root)** and Save.
The website URL is https://liangxiaozi.github.io/ once the Pages deployment finishes.
The `.nojekyll` file serves the static files directly.

## Edit

- `index.html`: content; `.zh` and `.en` spans contain paired translations.
- `styles.css`: blue/ivory design, responsive layouts and print styles.
- `script.js`: language preference and project filters. Expansion uses native HTML details.
- `assets/`: original SVG favicon and social graphic.

Content is based on the resume dated 2026-10-15. The WHO entry is listed without asserting authorship. The email is retained from the previous public site. The existing `cv.pdf` is an older asset and is not linked as the latest resume. The source DOCX is ignored by Git. Legacy Jekyll configuration and layout are retained for reference but are bypassed by `.nojekyll`.
